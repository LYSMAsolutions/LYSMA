# Projets

## Role du fichier

Ce fichier sert à suivre les projets personnels, professionnels ou créatifs de Mathieu.

Chaque projet doit rester relié à une intention claire, un état actuel et une prochaine action concrète.

## Format recommande

Pour chaque projet :

* nom du projet ;
* catégorie ;
* intention ;
* résultat souhaité ;
* statut : idee, actif, en pause, termine, abandonne ;
* priorité : haute, moyenne, basse ;
* prochaine action ;
* blocages connus ;
* décisions associées ;
* date de dernière revue.
