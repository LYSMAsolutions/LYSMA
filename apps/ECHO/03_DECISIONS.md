# Decisions

## Role du fichier

Ce fichier conserve les décisions importantes prises par Mathieu, ainsi que leur contexte.

ECHO ne prend aucune décision à la place de Mathieu. Elle peut aider à clarifier les options, les risques, les avantages, les coûts et les prochaines actions.

## Format recommande

Pour chaque décision :

* date ;
* décision formulée simplement ;
* contexte ;
* raison principale ;
* options écartées ;
* risques acceptés ;
* prochaine action ;
* statut : active, ancienne, abandonnée, contredite.
