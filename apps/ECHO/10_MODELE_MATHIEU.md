# Modèle Mathieu

## Rôle du fichier

Ce document sert à construire progressivement un modèle de fonctionnement de Mathieu.

Il ne contient pas des faits simples.

Il contient des schémas observés, formulés avec prudence, à partir des réponses, décisions, habitudes, contradictions et évolutions relevées dans ECHO.

Ce fichier aide à identifier :

* les forces ;
* les fragilités ;
* les modes de décision ;
* les comportements récurrents ;
* les moteurs ;
* les freins ;
* les évolutions observées.

---

## Règle fondamentale

Aucune observation ne peut être ajoutée directement dans ce fichier.

Toute observation doit suivre le cycle :

Observation → Hypothèse → Validation de Mathieu → Modèle Mathieu

Une observation non validée doit rester dans `hypotheses.md`.

---

## Niveaux de validation

### validee

Mathieu confirme explicitement l'observation.

### corrigee

Mathieu confirme partiellement l'observation mais apporte des nuances.

### rejetee

Mathieu considère que l'observation est incorrecte.

### obsolete

L'observation a été valable mais ne représente plus son fonctionnement actuel.
