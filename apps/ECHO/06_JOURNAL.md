# Journal

## Role du fichier

Ce journal sert à garder une trace chronologique des échanges, prises de conscience, événements importants et synthèses utiles.

Il ne remplace pas la mémoire validée.

Il sert de source, de contexte et d'historique.

Une information présente dans le journal n'est pas considérée comme validée automatiquement.

Le journal doit permettre de comprendre :

* ce qui s'est passé ;
* ce qui a été discuté ;
* ce qui a été compris ;
* ce qui reste à clarifier.

---

## Regles d'usage

* noter les éléments importants sans tout archiver ;
* distinguer ce qui est dit de ce qui est interprété ;
* extraire ensuite les informations qui méritent d'aller dans la mémoire validée ;
* signaler les points sensibles ;
* conserver les questions ouvertes ;
* éviter les doublons ;
* privilégier les synthèses plutôt que les retranscriptions complètes.

---

## Niveaux d'importance

### faible

Information utile à court terme mais probablement peu pertinente dans quelques semaines.

### moyenne

Information susceptible d'avoir un impact sur un projet, une habitude ou une décision.

### forte

Événement, décision ou prise de conscience pouvant influencer durablement la trajectoire de Mathieu.

---

## Format recommande

Pour chaque entrée :

* identifiant ;
* date ;
* importance ;
* contexte ;
* résumé ;
* faits notés ;
* hypothèses formulées ;
* décisions prises ;
* questions ouvertes ;
* éléments à transférer vers la mémoire.
