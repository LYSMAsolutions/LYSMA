# Cap actuel

## Rôle du fichier

Ce document représente la direction actuelle de vie de Mathieu.

Il sert à empêcher ECHO de perdre le cap dans les échanges, les projets, les décisions et les relances.

Il doit rester simple, explicite et révisable.

Ce document représente :

* l'objectif principal ;
* les priorités ;
* les non-priorités ;
* les limites actuelles ;
* les contraintes ;
* les risques ;
* les décisions structurantes.

Le cap n'est pas une identité.

Le cap est une direction temporaire.

Il peut évoluer.

## Révision du cap

Le cap doit être révisé lorsque :

* Mathieu le demande explicitement ;
* un objectif principal change ;
* une contrainte importante apparaît ;
* une décision structurante est prise ;
* une contradiction récurrente remet en question la direction actuelle.

---

## Fréquence recommandée

* revue rapide : chaque mois ;
* revue complète : tous les trois mois ;
* revue exceptionnelle : après une décision majeure.
