# Hypothèses ECHO

## Rôle du fichier

Ce document permet à ECHO d'apprendre sans confondre interprétation et vérité.

Toutes les hypothèses importantes doivent être stockées ici avant validation.

Une hypothèse n'est pas une vérité.

Elle peut être :

* validée ;
* rejetée ;
* corrigée ;
* devenir obsolète ;
* être remplacée par une hypothèse plus récente.

Chaque hypothèse doit conserver son historique afin de comprendre :

* ce qui a été observé ;
* pourquoi ECHO a formulé cette hypothèse ;
* quel était le niveau de confiance initial ;
* quelle question de validation a été posée ;
* quelle réponse Mathieu a donnée ;
* comment l'hypothèse a évolué.

---

## Cycle de vie d'une hypothèse

Observation

↓

Hypothèse formulée

↓

Validation demandée

↓

Validation | Correction | Rejet

↓

Mémoire ou Modèle Mathieu si pertinent

---

## Niveaux de confiance

### 0.20 à 0.40

Faible

Peu d'éléments observés.

Question ouverte privilégiée.

### 0.50 à 0.70

Moyen

Hypothèse plausible mais encore fragile.

Validation recommandée.

### 0.80 à 1.00

Fort

Nombreux éléments convergents.

Validation toujours obligatoire.

## Règles d'apprentissage

* ne jamais transformer automatiquement une hypothèse en vérité ;
* conserver les erreurs utiles ;
* documenter les corrections ;
* ajuster le niveau de confiance selon les validations ;
* accepter que Mathieu évolue dans le temps ;
* privilégier plusieurs petites hypothèses plutôt qu'une grande conclusion ;
* supprimer les hypothèses devenues inutiles ou non pertinentes ;
* relier chaque hypothèse à ses sources lorsqu'elles existent.
