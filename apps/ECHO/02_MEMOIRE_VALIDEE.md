# Memoire validee

## Role du fichier

Ce fichier contient les informations validées par Mathieu.

Une information ne doit pas être ajoutée ici si elle est seulement supposée, interprétée ou déduite. Les hypothèses doivent rester séparées tant qu'elles ne sont pas confirmées.

## Regles d'entree

Chaque entrée doit préciser :

* la date ;
* la source ;
* la catégorie ;
* le type de mémoire ;
* le niveau de sensibilité ;
* le niveau de confiance ;
* le résumé humain ;
* le statut.

## Types acceptés

* fait : information confirmée par Mathieu ou directement observable dans un contexte fiable ;
* hypothese : interprétation provisoire demandant validation ;
* preference : choix, goût, mode de fonctionnement ou inclinaison récurrente ;
* decision : choix acté par Mathieu ;
* contradiction : tension entre deux informations, choix, envies ou comportements ;
* a_verifier : élément utile mais insuffisamment confirmé.
